# Cancer Risk Prediction App

A Streamlit web application that predicts cancer risk based on patient clinical and lifestyle data, using a trained Logistic Regression model (94.6% accuracy).

Built as part of the NAVTTC × NeXskill – Be Productive Data Analytics program, under instructor Sir Atif Siddiqui.

## How It Works
The app takes patient inputs (clinical and lifestyle factors) and returns a cancer risk prediction using a pre-trained scikit-learn model.

## Tech Stack
- Python
- Streamlit (web interface)
- scikit-learn (model)
- pandas, joblib

## Files
- `cancer_risk_prediction.py` — Streamlit app
- `cancer_prediction_model.pkl` — trained ML model
- `requirements.txt` — dependencies
